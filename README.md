This project demonstrates basic CI/CD using GitHub Actions and Super-Linter.
All development is done on the dev branch, then merged into main through a pull request reviewed by a collaborator.

Features

Super-Linter checks code on every push and pull request

dev → main workflow with peer review

Collaborator approval before merging

Automatic linting on merge

Purpose

To practice CI, branching, collaboration, and automated code checks as part of Assignment 12.
