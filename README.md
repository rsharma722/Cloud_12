# Assignment 12 - CI/CD with GitHub Actions

This repository demonstrates a basic CI/CD workflow using GitHub Actions and Super-Linter.

## What it shows

- Continuous Integration with Super-Linter on pushes and pull requests
- Development on a `dev` branch
- Peer review before merging into `main`
- Linting triggered automatically after merge

## Purpose

Practice CI, branching, collaboration, and automated code checks for Assignment 12.
